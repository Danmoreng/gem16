# imp reference lane — Fast Track R4

Imp is an optional source of failure-mode evidence and isolated kernel ideas. It is not a runtime dependency, format authority or critical-path backend.

## Allowed uses

- compare router/shared/expert semantics against pinned captures;
- study producer-specific NVFP4 scale conventions;
- study isolated grouped small-M scheduling after M13 correctness exists;
- use external quality/performance results as clearly labeled context.

## Timing

- source/license and semantic research may run in parallel with M06/M10;
- no imp production code enters the base runtime before M13 passes;
- an isolated M14/M15 kernel idea may be adopted only with exact provenance, license review, independent tests and adjacent A/B evidence;
- ModelOpt or imp comparison belongs to conditional M18 or final contextual reporting, not the early quality gate.

## Rejected imports

Do not import paged KV, host expert offload, a general executor, broad GGUF dispatch, a second permanent weight layout or continuous batching.
