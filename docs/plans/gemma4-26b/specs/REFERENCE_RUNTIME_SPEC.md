# Reference runtime use — Fast Track R4

References answer different questions:

- locked Transformers/QAT BF16: mathematical and teacher-forcing authority;
- direct Unsloth NVFP4: practical NVFP4 comparison;
- official Q4_0 in a pinned runtime: external QAT-target-format context;
- Gem16 CPU/CUDA reference paths: implementation-local correctness.

No external runtime is an implicit dependency or format authority. Pin exact revisions and record timing/caching differences. An internal Q4_0 backend is not required unless M24 is activated.
