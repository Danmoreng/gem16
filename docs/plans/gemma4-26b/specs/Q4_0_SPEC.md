# Q4_0 reference and optional-backend specification

Q4_0 is not part of the Fast Track base artifact contract. The official Google Q4_0 checkpoint remains an external quality/performance reference through its pinned runtime.

A native Gem16 Q4_0 codec, head or full backend may be implemented only under M24 or a targeted M18 diagnosis. Such work must:

- use exact block/nibble/scale semantics from a pinned source;
- preserve license and provenance for copied code;
- remain visibly distinct from native NVFP4 execution;
- avoid adding a second resident production representation;
- demonstrate a concrete diagnostic or product benefit.

No M06–M08 gate depends on this specification.
