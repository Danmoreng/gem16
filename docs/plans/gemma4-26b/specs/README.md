# Specifications — on-demand reading

Specifications are normative only when linked by the assigned milestone or active contract. Do not load the entire directory into every agent task.

- Compiler: native converter architecture, compiler CLI/schema, FP8/NVFP4 specs.
- Artifact/loader: derived checkpoint and provenance specs.
- Runtime correctness: MoE, attention/KV and reference runtime specs.
- Runtime performance: decode/prefill/head and CUDA lifecycle specs.
- Qualification: quality, benchmark and memory specs.
- Product/MTP: API/CLI, session ownership, memory and embedding/head specs.

`Q4_0_SPEC.md` is reference/optional M24 material, not a base-path prerequisite.
