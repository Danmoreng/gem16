- [ ] Scope matches one assigned slice.

- [ ] No silent fallback/offload/layout duplication.

- [ ] Relevant local and 12B regression tests ran.
- [ ] Full runs, if any, used a clean committed tree and exact preflight.
- [ ] Evidence paths and hashes match the implementation commit.
- [ ] Global status is updated only after merge/acceptance.
