# Before each milestone or sub-agent slice

- [ ] Read `AGENTS.md`, active contract, status JSON and the assigned milestone.
- [ ] Read only linked specs and targeted historical evidence.
- [ ] Confirm base commit and prerequisites.
- [ ] Declare writable paths, read-only interfaces and merge dependency.
- [ ] Select the applicable test tier.
- [ ] Confirm full runs are not planned from a dirty worktree.
- [ ] Record explicit non-goals.
