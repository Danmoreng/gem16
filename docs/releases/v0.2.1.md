# gem16 0.2.1

gem16 0.2.1 is a stable bugfix update for Windows x64 and Linux x86-64,
including Studio plus server packages and separate headless server archives.

## Fixes

- Coding-agent Chat Completions requests can use `frequency_penalty` and
  `presence_penalty` in `[-2, 2]`, including the neutral zero values used by
  clients. Active values use native GPU sampling and current-response output
  counts, with support for ordinary and fixed-D2 decoding. Resident KV prefixes
  and RNG progress survive coefficient changes; counters reset per response.
- Studio Light mode uses the former interface's neutral white/gray surfaces,
  forest-green accents and mint containers. Chat bubbles, reasoning, Markdown,
  code, status labels, logs and form controls now follow the selected theme.
  Switching back to Dark mode restores its widget colors.
- Animated green/mint background waves and navigation highlights are visible
  in Light mode on a bright background, with readable text and opaque chat/code
  surfaces. Both OpenGL and Direct3D shader implementations are updated.

## Validation scope

- The penalty implementation has bounded Windows GPU, CPU-reference,
  sanitizer, zero-path comparison, streaming, function-tool and disconnect
  recovery evidence for both public profiles in ordinary and fixed-D2 modes.
- Linux checks at the penalty implementation revision `0e61daa` passed host
  and Studio tests, the CUDA operator suite, sampling memcheck (zero errors),
  a raw-token repetition reference and protected 12B product regression.
  Public-profile HTTP/lifecycle tests and internal NVFP4 ordinary/fixed-D2
  checks also passed. The internal check used a verified temporary hardlink
  view excluding aggregate Hub metadata and other component directories.
- Light theme checks cover text contrast and Dark/Light/Dark color restoration.
  Linux Studio tests pass; the actual background/navigation shaders render and
  animate without OpenGL errors on the RTX 5080 Laptop GPU. Windows HLSL entry
  points passed a syntax compilation check; that is not a Windows GPU visual test.
- Release binaries are built from the exact `v0.2.1` tag. Cross-platform host
  CI includes Studio tests; both package workflows check host contracts and
  native Blackwell instructions. Archive hashes, contents, versions and
  headless manifests are checked before attachment. Hosted runners have no
  NVIDIA GPU and do not provide model-execution qualification.

This patch is published by explicit owner direction using the bounded evidence
above. The extended C07/C08 clean-machine, exact-candidate GPU/quality and full
qualification-manifest campaign remains open and is not claimed as passed.
Earlier Windows/Linux model results are retained evidence at their recorded
revisions, not new exact-tag model tests.

## Known limitations

- New per-request penalty controls apply to Chat Completions. Responses is
  unchanged; repetition and other sampling settings remain startup/session
  configuration. Greedy mode rejects active frequency/presence penalties
  before generation instead of ignoring them.
- Reasoning replay, other per-request sampling overrides, required/named tool
  choice and `parallel_tool_calls=false` remain outside the supported Agent
  Core subset. Full external-agent compatibility is not claimed.
- Penalties were checked at bounded context sizes; media and everyday-context
  execution were not requalified. In the retained 12B small-image recall probe,
  one of four semantic cases passed; robust small-detail recall is not claimed.
- Model downloads and declared platform libraries remain external. Packages
  are not universally self-contained. One local user on loopback remains the
  supported server boundary; remote multi-user serving, authentication and TLS
  are outside this release.
