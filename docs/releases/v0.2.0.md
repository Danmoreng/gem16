# gem16 0.2.0

gem16 0.2.0 is the stable Windows x64 and Linux x86-64 release of the local
Gemma 4 inference engine, OpenAI-compatible local agent server and optional
native Studio for NVIDIA Blackwell SM120/SM120a GPUs with approximately 16 GB
of VRAM.

## Included profiles

- Gemma 4 12B Unified: text, image and audio, with optional fixed-D2 decoding.
- Gemma 4 26B A4B Compact Vision: Trellis35 text plus FP8 Vision, ordinary or
  fixed-D2 decoding, including multiple images within context capacity.
- The qualified text-only 26B NVFP4 path remains an internal regression and
  rollback profile and is not offered in the normal Studio model selection.

## Highlights

- Native CUDA inference paths for Blackwell with verified OMMA/QMMA dispatch.
- Local Chat Completions and Responses APIs with streaming and client-executed
  function tools.
- Python OpenAI SDK, TypeScript OpenAI SDK and Pi coding-agent workflows.
- Conversation resume, fork, compaction, cancellation, graceful restart and
  bounded session-slot recycling.
- Native Windows and Linux Studio packages plus separate headless server
  archives.

## Validation scope

- Linux C03-C06 phase, cancellation, media/history, SDK, Pi lifecycle,
  compaction, cold-resume and client-boundary checks passed for both public
  profiles on an RTX 5080 Laptop GPU.
- Windows C03-C06 and SDK/Pi evidence from the preceding candidate remains
  retained. The final v0.2.0 source revision passed cross-platform Windows and
  Linux host, Studio, Python and TypeScript CI.
- The CUDA release build, bounded CUDA/host tests and native instruction checks
  passed on Linux before the release freeze.

By explicit owner decision, the extended C07 clean-machine/provenance gate and
C08 exact-candidate two-platform GPU/quality campaign were not required for
v0.2.0 and are not claimed as passed. Final-revision Windows GPU verification is
planned after publication; a material Windows-specific defect will be corrected
in v0.2.1.

## Known limitations

- In the bounded C04 12B small-image recall probe, one of four semantic cases
  passed. Image input remains available, but this release does not claim robust
  small-detail recall across that probe.
- Reasoning replay, per-request sampling overrides, required/named tool choice
  and `parallel_tool_calls=false` are outside the supported Agent Core subset
  and fail visibly rather than silently changing semantics.
- The archives depend on the declared platform libraries and pinned external
  model downloads; they are not described as universally self-contained.
- The supported server boundary is one local user on loopback. Remote multi-user
  deployment, authentication and TLS are outside this release.
