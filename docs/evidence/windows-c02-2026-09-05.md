## Changes

- Build a complete replacement Responses chain before its noexcept move into
  the resident entry. An allocation failure preserves the previous host chain;
  the request's lease still governs discard after state-mutating failures.
- Remove the temporary string allocation from `UnindexResponse`, which is used
  by destructor cleanup. Remove redundant error-path reservation/index cleanup.
- Catch exceptions inside deferred Chat Completions and Responses body providers.
  httplib's routing exception handler does not cover their later execution.
  Fail closed, count the failed request, discard the lease and remove unfinished
  response indexes/active IDs. Ordinary final-chunk write failure after a completed
  Responses commit retains its existing semantics.
- Use Bash quoting and forward-slash interpreter paths in the Pi fixture. On
  timeout, terminate the owned process tree before deleting its temporary working
  directory. Retain a structured failed result with exit code 124 on timeout.

## Negative evidence and limits

The first allocation test raised a visible MSVC debug-runtime abort dialog.
MSVC's checked STL containers allocate iterator proxies inside noexcept
constructors, so arbitrary allocation injection into that debug implementation
can terminate before application exception handling. The test now explicitly
skips that configuration (CTest code 77), runs against the Release STL used by
the server, and directs CRT diagnostics to stderr rather than a dialog. This
does not claim recoverability of all MSVC debug-STL out-of-memory conditions.

The first 12B Pi run exceeded its 180-second limit and cleanup failed with
WinError 32 on the temporary project. Other checks and the 26B Pi run passed.
The initial matrix remains failed and retained. After the harness correction,
both complete matrices passed; the initial agent timeout is not retroactively
reclassified as a pass or proven to have only one cause.

Systematic session publication/acquisition/generation/index/serialization fault
injection with real GPU slot recovery remains open. The current host injection
tests the Responses commit and callback boundary, not every server lifecycle
stage. C03 long-prefill cancellation and later full qualification gates remain
open. Linux execution has not been repeated for this slice. No new benchmark
measurement, commit, push or publication was performed.
