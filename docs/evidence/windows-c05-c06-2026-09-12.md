The lifecycle probe uses Pi's regular RPC and saved JSONL sessions, with no agent
source modification or HTTP proxy. Automatic compaction is triggered with a

and completes with reason `threshold`, `aborted=false` and an actual result. The
subsequent answer retains the codeword and project language. This is not qualification

Cold resume loads a copy of the retained parent file in an entirely new Pi process
and server process. The original empty, disposable harness working directory is
recreated because Pi requires the saved cwd to exist. The session header/messages
and session ID are unchanged; original evidence files are never edited. The fixture
directory is removed only if the harness created it and it is empty.

  The harness now restores only the validated disposable fixture cwd and reports
  child exit promptly. Only the failed 12B case was repeated after 26B passed.
