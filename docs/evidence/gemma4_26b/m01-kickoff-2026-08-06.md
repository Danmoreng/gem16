## Relevant drift

The M01 parent differs from the plan anchor in `docs/CHECKPOINT_FORMAT.md`, `docs/CORRECTNESS.md` and the addition
of `docs/DEVELOPMENT.md`. The current repository has a mature immutable 12B lock/cache/fetch path, model-backed
correctness tooling and stricter checkpoint/compiler policy than the anchor. The inspected M01 implementation
surfaces remain 12B-specific:

- `tools/fetch_model.py` accepts lock schema 1/2 and top-level full 40-hex revisions, but has no capacity plan or
  nested destination support;
- `tools/hf_cache.py` has fixed 12B target/assistant defaults;
- the existing source lock records exact bytes, SHA-256, Git/LFS/Xet identity and per-file source overrides;
- existing Python tests cover composed cache views, source overrides and resumable downloads, but not full lock
  schema validation, capacity rejection or multi-shard non-duplication.

No 26B compiler, loader, runtime or CUDA path exists. M01 will not add one.

## Local storage and memory preflight

Measured on the selected filesystem before M01 downloads:

- available filesystem bytes: 289,218,441,216 (269.356 GiB);
- physical memory: approximately 62 GiB;
- swap: none;
- existing model tree: approximately 23 GiB;
- the official text Q4_0 payload is already present locally and still requires lock/hash verification;
- additional QAT BF16, ordinary BF16 and Unsloth repository payload: 120,230,781,280 bytes (111.974 GiB).

All four complete source repositories total 135,865,004,079 bytes (126.534 GiB). After the three missing source
repositories, one 14,100 MiB derived artifact and one equally sized temporary output, the filesystem would retain
approximately 129.843 GiB. This passes the initial storage preflight only if cache views use hardlinks/symlinks and
the compiler remains streaming/bounded as required. Accidental cache duplication is a stop condition.

The 62 GiB/no-swap host is not yet qualified for a complete BF16 Transformers reference run. M01 must measure the
actual reference loading plan before declaring local execution safe; otherwise it must record a larger-host or
explicit staged diagnostic plan. This uncertainty does not block metadata locks or verified source download.

## Immediate boundaries

- Do not place tokens, signed download URLs or private model data in repository evidence.
- Do not download large payloads before immutable metadata and capacity checks are executable.
- Do not execute repository model code or use `trust_remote_code`.
- Do not duplicate Hugging Face cache blobs into model views.
- Stop on source revision/config drift, insufficient space or any unverified byte.
