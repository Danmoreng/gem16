## Authorization and scope

The owner accepted M01 and authorized M02 from the final M01 closure. M02 is limited to host-side configuration
parsing, explicit model classification/static traits, exact 26B architectural validation, inspect/capability
metadata and tests. Tensor upload, memory planning for 26B, checkpoint compilation, runtime arithmetic and CUDA
kernel changes are out of scope. The 12B and assistant execution contracts must remain exact.

M02 changes no model arithmetic, precision, resident bytes, workspace bytes or benchmark behavior. Its parent
comparison is the existing Host Debug and Blackwell Release CTest suites at `59996f5`.

## Locked 26B configuration facts

The canonical fixture is the QAT-BF16 `config.json` from source revision
`f1e06dc520982d9b9edd76859fdb7ab209449949`: 3,810 bytes, SHA-256
`ece3392c07744553f4e8bb2b5905bc68b0a7d7ab2927133bb621875b8e4a3289`. M01 proves the ordinary-BF16 and Unsloth
text architecture contracts are equivalent. The exact text contract includes 30 layers, hidden size 2,816, shared
MLP width 2,112, routed-expert width 704, 128 experts, top-8 routing, 16 query heads, 8 local KV heads, 2 global KV
heads, no KV sharing, local/global head widths 256/512, a 1,024-token local window and 262,144-token maximum
context. Layer types are five sliding layers followed by one full-attention layer, repeated five times.

The source config carries a Gemma 4 vision sub-config and no audio sub-config. The first product capability remains
text-only: vision, audio, video and MTP execution must report unsupported even though source modality metadata is
validated for identity.

## Planned tests and stop conditions

Host tests will cover the locked positive fixture, exact variant/capability traits, every new MoE dimension, layer
count/pattern, attention/KV fields, RoPE and modality metadata, zero/oversized values, unknown Gemma 4 rejection and
unchanged 12B/assistant behavior. Existing Host Debug and Blackwell Release CTests remain required. A mismatch
between the locked fixture and the M01 contract, any changed 12B behavior, or any accidental 26B execution
eligibility is a stop condition.
